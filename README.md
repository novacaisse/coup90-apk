# Coup90 pour Android

Application de pronostics football **Coup90** (service d'information, réservé aux 18 ans et plus, aucun gain n'est promis).

**Téléchargement direct (dernière version) :**
https://github.com/novacaisse/coup90-apk/releases/latest/download/coup90-latest.apk

Page officielle : https://coup90.app

## Mise à jour du fichier (équipe Coup90)

Onglet **Actions** → « Publier l'APK » → **Run workflow** :
- `source_url` : adresse https publique du nouvel APK ;
- `tag` : nom de la version (exemple `v2.5.1`).

Le fichier est contrôlé (archive Android valide), copié dans une nouvelle Release et devient automatiquement le « dernier » lien ci-dessus.
